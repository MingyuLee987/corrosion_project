# 조성 입력 확장 비교

144행 데이터의 기존 모델은 C·Cr·Ni·Mo와 총 희토류 함량 변환값을 사용했지만, Si·Mn·P·S·Cu는 입력에서 빠져 있었다. 주요 조성 정보를 추가할 필요가 있어, 공정·환경·상 입력과 GBR 설정을 고정하고 조성 입력만 비교했다. 데이터 CSV의 196컬럼은 변경하지 않았다.

| 입력 구성 | 전체 학습 R² | 전체 시험 R² (28행) | 희토류 학습 R² | 희토류 시험 R² (6행) | 학습 내 논문별 CV 희토류 R² (27행) |
|---|---:|---:|---:|---:|---:|
| 기존 14입력 | 0.9475 | 0.8406 | 0.9826 | 0.8052 | −0.4817 |
| Si·Mn·P·S·Cu 추가, 19입력 | 0.9477 | **0.8573** | 0.9809 | **0.9597** | **−0.4125** |
| 위 구성에 N·Al·Nb·V·Ti·Co·O 추가, 26입력 | 0.9478 | 0.8384 | 0.9798 | 0.9420 | −0.4329 |

R²는 `log10(icorr_A_cm2)` 기준이다. 116행 학습 자료에서 논문 단위 GroupKFold 4분할을 적용해 입력 구성을 먼저 선택한 후, 기존 시험 record_id 28개를 유지하여 비교했다. 선택 점수는 논문별 CV에서 모은 희토류 27행의 R²이다. 시험 점수로 입력을 선택하지 않았다. CV는 입력 선택에 사용한 지표이므로 독립 검증 점수가 아니다.

선택된 주요 조성 확장 모델에서 희토류 시험 log10 MAE는 0.2696에서 **0.1201**로 줄었고, 2배 이내 적중은 4/6에서 **6/6**으로 늘었다. 그러나 시험 시료가 6행뿐이며, 기존 행 단위 시험을 재사용했다. 같은 논문의 다른 시료가 학습과 시험에 존재할 수 있으므로 새 논문에 대한 예측 성능을 이 점수로 보장할 수 없다. 논문별 CV R²가 여전히 음수라는 점을 함께 보고해야 한다. R²=0.9597은 95.97% 적중률을 뜻하지 않는다.

## 선택한 19개 입력

- 조성: `C_wt_pct`, `Cr_wt_pct`, `Ni_wt_pct`, `Mo_wt_pct`, `Si_wt_pct`, `Mn_wt_pct`, `P_wt_pct`, `S_wt_pct`, `Cu_wt_pct`
- 희토류: `RE_log1p_ppm` = log(1 + RE_wt_pct × 10000), `RE_element_cat`
- 조성 파생값: `high_Cr_indicator` (Cr ≥10.5 wt% 여부)
- 시험 조건: `chloride_molar_verified`, `temperature_C`, `log_pre_exposure_verified`, `TP_scan_rate_mV_s`, `log_OCP_s`, `gas_condition_cat`
- 보고된 모재 상: `matrix_family_reported`

조성 컬럼은 합금 원소의 질량 백분율(wt%)이다. `S_upper_bound_wt_pct`처럼 상한만 보고된 값은 정확한 `S_wt_pct`로 대신 넣지 않았다. `RE_nominal_wt_pct`는 투입 목표값일 수 있으므로 실제 조성과 중복되는 독립 입력으로 넣지 않았다. `La_wt_pct`와 `Ce_wt_pct`는 각각 6/144행과 12/144행만 확인되어, 현재는 총 희토류량과 원소 종류를 유지한다. 혼합 희토류의 개별 최종 함량을 투입 비율로 계산하지 않았다.

## 조성 결측 현황

| 조성 | 값이 있는 행 /144 |
|---|---:|
| C | 140 |
| Si | 141 |
| Mn | 144 |
| P | 101 |
| S | 105 |
| Cr / Ni | 각각 93 |
| Mo | 71 |
| Cu | 58 |
| N / Al | 26 /31 |
| Nb / V / Ti | 18 /24 /13 |
| Co / O | 각각 11 |
| W / Ca | 각각 0 |

미보고 조성을 0%로 해석하지 않았다. 수치 결측은 각 학습 분할에서 구한 중앙값으로 대체하고 결측 표시를 함께 입력했다. 따라서 미량 원소 추가가 실제 원소 효과보다 특정 논문의 보고 관행을 학습할 가능성도 있다. 다음 자료 수집에서는 주요 조성, 특히 Cr·Ni·Mo·Cu와 일관된 시험 조건을 더 완전하게 확보하는 것이 필요하다.

## 재현 및 모델

`.venv/Scripts/python.exe compare_composition_inputs.py`

[전체 결과](validation.json), [조성별 결측률](composition_coverage.csv), [선택 모델의 시료별 예측](main_composition_predictions.csv)을 보관했다. `model_train_only.joblib`는 116행 비교 모델이고, `model_all144.joblib`는 선택한 19입력으로 144행을 전부 학습한 실험용 모델이다. 전체 학습 모델에는 위 시험 점수를 독립 시험 결과로 붙일 수 없다. 기존 기본 모델은 자동 교체하지 않았다.
