# 19입력 GBR 교차검증 R²

기존 시험 28행을 제외한 **116행(희토류 27행)**에서 4분할 교차검증했다. 각 검증 행은 해당 행을 학습하지 않은 모델로 한 번씩 예측했다. 결측 대체·표준화·범주 인코딩·상수 입력 제거는 각 분할의 학습 자료에서만 수행했다. 모델 설정과 입력 후보는 이번 계산에서 변경하지 않았다.

| 구분 | 전체 | 희토류 첨가 |
|---|---:|---:|
| 학습 R² | 0.9477 | 0.9809 |
| 행 단위 교차검증 R² | **0.8217** | **0.7782** |
| 논문 단위 교차검증 R² | **−0.2428** | **−0.4125** |
| 기존 시험 R² | 0.8573 | 0.9597 |

모두 `log10(icorr_A_cm2)` 기준이다. 교차검증 표의 값은 검증 예측을 모두 모아 계산한 pooled out-of-fold R²이며, 4개 분할의 R²를 단순 평균한 값과 다르다. 행 단위 분할은 희토류 여부를 층화하여 seed=17로 고정했다. 논문 단위 분할은 reference_id를 그룹으로 사용하여 동일 논문이 각 분할의 학습과 검증에 동시에 들어가지 않도록 했다.

행 단위 검증에서는 같은 논문의 다른 시료가 학습에 들어갈 수 있다. 논문 단위 검증은 학습하지 않은 논문의 시료에 대한 예측을 평가하므로, 새 문헌에 대한 예측력 판단에는 더 직접적이다. 음수 R²는 검증 관측값 평균을 상수로 예측하는 기준보다 제곱오차가 크다는 뜻이다.

희토류 행 단위 검증 적중률은 2배 이내 **15/27 (55.6%)**, 3배 이내 **20/27 (74.1%)**, 5배 이내 **25/27 (92.6%)**, 10배 이내 **27/27 (100%)**이다. 논문 단위 검증에서는 각각 **6/27 (22.2%)**, **7/27 (25.9%)**, **10/27 (37.0%)**, **15/27 (55.6%)**이다.

19입력 구성은 앞선 실험에서 같은 학습 자료의 논문별 검증 점수로 선택되었다. 따라서 이 결과는 **모델 개발용 교차검증**이며, 선택 과정까지 바깥 분할에 포함한 독립적인 중첩 검증 결과가 아니다. 기존 시험도 이전에 관찰한 6행의 희토류 시료를 재사용하므로, 0.9597만으로 높은 일반화 성능을 주장해서는 안 된다.

논문별 일부 분할의 희토류 목표값 범위가 좁아 분할 R²가 매우 큰 음수가 되는 경우가 있다. 분할별 R²와 단순 평균은 [validation.json](validation.json)에 함께 보관했으며, pooled 점수와 혼용하지 않는다.
