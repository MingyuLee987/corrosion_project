# 추가 상 검증 및 모델 비교

2026-10-13. La 첨가 Q355 논문의 Sec3.1 Figure2a–d에서 시편별 조직을 확인하여 기존 희토류 데이터 4행의 상 정보를 보완했다. 원문: https://www.mdpi.com/1996-1944/17/18/4467 . 67ppm은 펄라이트/다각형 페라이트/입상 베이나이트/준다각형 페라이트, 110ppm은 펄라이트/다각형 페라이트/입상 베이나이트, 230ppm은 명시적으로 보고된 침상 페라이트, 310ppm은 펄라이트/침상 페라이트를 기록했다. 열거한 구성요소는 저자가 명시한 것으로 다른 구성요소가 없다는 뜻이 아니다. 미첨가 대조군 조직과 분율은 임의 추정하지 않았다. 확장 데이터에서 보고 상이 있는 행은 21→25행, 기존 314행에서는 9→13행이다.

상/조직 입력과 결정립·분율 추가 입력에 대해 Random Forest 및 Extra Trees 각 최소 잎 표본수3/8(64 trees), 보조 가중치0.25를 비교했다. 상/조직 포함 SVR C0.1/0.3, gamma scale, epsilon0.1, 보조 가중치0.25/1도 비교해 총12개 설정을 평가했다. 비교 범위를 사전에 정한 후 이번 결과를 계산했으며, 앞선 탐색 이력이 있는 자료라는 한계는 유지된다.

| 평가 | log10(icorr) R² |
|---|---:|
| 이번 최고 고정 설정의 논문 제외 평가 | **0.1932** |
| 모델 설정 선택까지 포함한 중첩 논문 제외 평가 | **0.1292** |
| 전체326행 학습 후 같은 RE>0 41행 재예측 | 0.8158 |
| 전체326행 학습 후 같은 전체326행 재예측 | 0.2125 |

최고 탐색 모델은 SVR C0.1/gamma scale, 보조 가중치1, 상·조직 포함/결정립·분율 제외다. RE 평가 표본은 이전과 동일한41행·13편으로 유지했다. 같은 논문의 모든 대조군 및 첨가군을 바깥/안쪽 학습에서 제외하며, 대치·스케일링은 학습 자료에서만 수행한다. 추가된 상 컬럼도 평가 논문에서 학습으로 유입되지 않는다. 검증 후 최종 모델은326행 전체로 다시 학습했다.

이전 상 포함 중첩 검증 -0.1087보다 이번0.1292가 높지만 **상 보완과 탐색 설정이 동시에 달라졌으므로 개선을 상 효과만으로 해석하지 않는다.** 아직 독립적인 새 문헌 검증이 필요하다. 이전 상 제외 최고 탐색값0.2111을 넘은 것도 아니다. 학습 R²를 최고로 만드는 대신 논문 제외 예측력을 설정 선택 기준으로 사용했다.

재실행: `.venv/Scripts/python.exe -X utf8 -B tune_phase_model.py --algorithms`

모델: `results/phase_algorithms_v2/model_all326.joblib`

예측: `.venv/Scripts/python.exe -X utf8 -B predict_phase_model.py input.csv output.csv --model results/phase_algorithms_v2/model_all326.joblib`

`comparison.csv`, `validation.json`, `predictions.csv`에 전체 설정 점수와 선택·예측·입력 해시를 저장했다. 이전 phase_tuning 결과/모델은 해당 시점의 기록으로 보존했다. 기존 부식전류와 행 수는 바꾸지 않았다.
