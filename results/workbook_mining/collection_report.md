# 49편 문헌 데이터마이닝 수집 결과

사용자가 지정한 기준은 원본 데이터마이닝 시트의 모든 측정 컬럼이다. 원본은 총 38컬럼이며 논문번호·강종·시료 3컬럼과 추정 표시 1컬럼을 제외하면 측정·계산 항목은 34개다. 원본 엑셀은 수정하지 않았다.

## 확보한 자료

| 구분 | 수 |
|---|---:|
| 문헌 목록 | 49편 |
| 연결된 시편·시험조건을 수집한 문헌 | 26편 |
| 수집 행 | 114행 |
| 기존 프로젝트에서 유지한 행 | 32행 |
| 이번에 원문에서 새로 전사한 행 | 82행·17편 |
| 정규화 가능한 숫자 icorr 보유 행 | 57행 |
| 그중 이번 수집의 숫자 icorr 보유 행 | 25행 |
| 단위 충돌로 정규화 타깃을 비워 둔 행 | 11행 |
| 전체 34개 항목이 모두 확보된 행 | **0행** |

114행은 결측 없는 학습 데이터가 아니다. 조성이 있는 시편, 타깃이 있는 시험조건, 타깃 충돌을 확인한 시편을 함께 보존한 문헌 수집표다. 57행도 모든 원소·공정·시험조건이 갖추어진 학습 데이터라는 뜻이 아니다. 벌크 희토류강, 산화물 분산강, 표면 확산층, 용접금속을 포함하므로 같은 예측 모집단으로 무조건 합치면 안 된다. `eligible_under_requested_all_column_policy`는 전부 False다. 기존 50행 학습 데이터와 모델은 교체하지 않았다.

현재 23편은 수집표에 연결된 시편을 넣지 못했다. 49편 전부를 원문 재검증했다거나, 얻을 수 있는 모든 자료를 소진했다는 의미가 아니다. 49행 검토표에는 각 문헌의 이번 수집 상태와 미수집 여부를 명시했다. 원본 문헌정보의 Verified 표시는 사용자의 기존 표시이며, 이번 원문 검증 완료로 취급하지 않았다.

## 원본 시트에서 발견한 연결 문제

원본 시트는 값이 있는 행이 178개지만 조성·희토류 종류·시편 식별자가 같은 행에 올바르게 연결되어 있다고 볼 수 없다. 예를 들어 H13 연구가 표시된 행에는 저탄소강의 조성이 들어 있다. 원문 H13 Table1은 C 0.42/0.41, Si 0.98/0.87, Mn 0.41/0.49이며 P·S는 보고하지 않는다. 데이터마이닝 시트의 C 0.023/0.02/0.05 등과 대응하지 않는다. 논문·시편 정보가 없는 조성행은 앞 행의 논문번호를 전방 채움하여 합치지 않았다.

304-Y 논문(10.1038/s41598-018-23273-x) Table2는 Ecorr·Epit만 보고한다. 원본 시트의 5개 icorr 숫자를 원문 보고값으로 인정하지 않았다. HRB400 2026 논문 Table1의 Ipass도 icorr로 바꾸지 않았다. 316L ODS 논문은 Ecorr·Eb·재활성화 지표를 보고하며 icorr가 없어 공란을 유지했다.

## 단위·조성 문제

- S31254-Ce 2023 논문(10.11902/1005.4537.2022.135) Table1의 인쇄 단위는 `Icorr / 10^7 A cm^-2`로, 분극 곡선의 전류 규모와 맞지 않는다. 빠진 음수 부호를 추정해 10^-7로 고치지 않았다. 7행은 raw 값과 인쇄 단위를 보관하고 icorr를 공란으로 두었다.
- HRB500E 2024 논문 4행은 기존에 확인된 인쇄 전류 단위·본문 수치 충돌을 유지했다. C1은 정량 타깃 자체를 추출하지 않았다.
- 316H 표면 침크롬 논문의 Table1은 S 머리글이 두 번 등장해 0.75/0.015를 각각 보고한다. Si 또는 S로 임의 재배정하지 않았다. Cr 8, Ni 11 등 다른 인쇄값은 보존하고 강종과의 불일치를 표시했다. Y2O3 침투제 함량은 별도 컬럼이며 벌크 Y 함량으로 바꾸지 않았다.
- OffshoreCe25의 S<0.002는 실측 S=0.002로 입력하지 않았다. 별도 상한 컬럼에 보관했다.
- FCAW18 용접금속은 Table6의 실제 용접금속 조성을 사용했다. 모재 조성이나 플럭스 RE 투입량을 벌크 조성으로 대체하지 않았다.

## 결측 처리

미보고 원소를 0으로 채우지 않는다. 표의 대시, 미첨가 설계, 분석상 0은 서로 다른 근거다. 상온을 25°C로 바꾸거나 몰농도를 용액밀도 없이 wt%로 변환하지 않는다. 별도 질량감소·염수분무·습건반복·EIS 안정화 시간도 분극 시험의 침지시간으로 합치지 않는다.

PREN은 원본 시트에서 사용한 `Cr+3.3Mo+16N` 정의로 세 입력이 모두 있을 때만 계산하고 행 비고에 계산값이라고 표시했다. Fe의 Balance 표기는 원문 표기이며 100% 또는 임의 수치가 아니다. 원문에서 숫자로 보고되지 않은 항목은 그대로 미확보다. `missing_measurement_columns`에 각 행의 공란 항목을 적었다.
