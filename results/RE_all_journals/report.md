# 희토류 논문 확대 및 예측 검증 (2026-10-13)

사용자 요청에 따라 Q1/Q2 제한을 적용하지 않았다. 저널 등급을 임의로 부여하지 않았으며, 강재 내부의 희토류 첨가와 PDP 부식전류가 확인되는 자료를 수집했다.

## 데이터 추가

- `data/RE_all_journals_additions.csv`: 새 논문 2편, 대조군 포함 12행, RE>0 8행.
- `data/training_RE_all_journals.csv`: 기존 조건 보완 데이터 314행 + 신규 12행 = 326행. RE>0 평가 표본은 13편 41행이다.
- 기존 `training_RE_expanded.csv`, `training_PDP_augmented.csv`는 보존했다.
- 326행은 완전한 조성·공정을 확보한 300행을 뜻하지 않는다. 새 12행의 strict300 적격 행은 0이다.

| 논문 | 행 | 확인한 내용 | 남은 결측/검증 |
|---|---:|---|---|
| Special Steel 2025, DOI 10.20057/j.1003-8620.2024-00280 | 3 | Table2 조성, Table1 압연, Table4 icorr; PDF 59·62쪽 시각 확인 | P/S, OCP 시간, PDP 사전 노출 시간 미보고 |
| Chinese Rare Earths 2018, DOI 10.16533/j.cnki.15-1099/tf.201803014 | 9 | Table1 조성, Table2 icorr; 1·28·53일; 935°C 담금질/650°C 뜨임; 0.5mV/s | 웹 도구의 출판사 PDF 텍스트 확인; PDF 이미지 재확인 대기. 담금질 매체/열처리 유지시간, 수치 시험온도 없음 |

중국희토류 논문의 Y=0.15 wt%는 출판 Table1 값 그대로다. 0.015로 임의 수정하지 않았다. 동일 강의 여러 노출 시간은 서로 독립인 강 조성으로 세지 않고 논문 전체를 같은 검증 그룹으로 묶었다. Special Steel의 168h는 중량감량 시험 조건이므로 PDP 노출 시간으로 입력하지 않았다. 압연 전 가열·유지 조건도 최종 열처리 온도로 잘못 입력하지 않았다.

## R² 결과

모든 R²는 `log10(icorr_A_cm2)` 기준이다. 같은 논문의 대조군과 희토류 첨가군을 모두 학습에서 제외한다. 결측 대치와 스케일링은 학습 자료로만 계산한다.

| 평가 | R² | 해석 |
|---|---:|---|
| 새 논문 2편 RE>0 8행만 외부 평가, 기존 core8/SVR C0.3 고정 | -2.6444 | 새 두 논문을 학습에 사용하지 않음 |
| 같은 외부 8행, 기존 P/S 제거 + 제조공정/SVR C0.3 고정 | -2.1022 | 아직 새 문헌으로 일반화하지 못함 |
| 확장 41행, 동일 core8/SVR C0.3, 보조 가중치 1 | 0.1042 | 논문 제외 고정 설정 결과 |
| 확장 41행, P/S 제거 + 제조공정/SVR C1, 보조 가중치 0.25 | **0.2111** | 16개 설정 중 관찰한 최고값: 탐색 결과 |
| 확장 41행, 설정 선택까지 안쪽 논문 제외 검증으로 수행 | **-0.0105** | 중첩 검증 결과; 최적 탐색값과 구분해야 함 |

최고 탐색 조합의 log10 MAE는 0.5831, 논문별 균형 MAE는 0.7211이다. 아직 높은 정확도라고 주장할 근거는 없다. 이전 최고값 0.1634는 33행 평가였으므로 41행의 0.2111과 직접 상승률을 계산하지 않는다. 이전 고정 후보(C0.3/제조공정/보조가중치1)를 같은 역사적 33행에 평가하면 새 자료 추가 후 R²=0.0970으로, 기존 0.1634보다 낮아졌다.

이미 확보한 비희토류 공정 자료 66행을 추가하는 실험도 같은 RE 41행으로 비교했다. 가장 좋은 설정도 R²=-0.0929였으며, 최고 탐색 후보(C1/가중치0.25)는 0.2111→-0.2928이었다. 따라서 해당 66행은 이번 기본 학습 데이터에 합치지 않았다. 행 수 증가만으로 성능이 좋아지지 않는다는 결과를 보존했다.

## 컬럼 결정

- 유지: C, Si, Mn, RE 함량·종류, 전해질 종류.
- 우선 입력 후보: 가공 상태, 용해 경로, 냉각 방식, 실제 최종 열처리 온도·시간.
- P/S: 원본에는 보존하고, 현재 최고 후보의 모델 입력에서만 제외한다.
- 수집 우선: 담금질 온도·유지시간·매체, 뜨임 온도·유지시간, 압연 시작/종료 온도·압하율, PDP 직전 노출 시간, 수치 시험온도·pH·염화물 농도.
- 압연 가열과 최종 열처리를 별도 컬럼에 기록한다. 여러 열처리 단계의 시간/온도를 하나의 값으로 섞지 않는다.
- icorr를 같은 전기화학 시험에서 추정하는 Ecorr, Tafel 기울기, Rp/Rct 및 수동태 전류는 공정조건 예측기의 입력으로 추가하지 않는다.
