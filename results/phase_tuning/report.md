# 상 정보 포함 모델 최적화 및 전체 행 학습

2026-10-13. 조성·공정에 보고된 상/조직 구성요소를 추가하고, 결정립 크기·페라이트 분율 포함 여부도 비교했다. 2개 입력 조합 × SVR C 4개(0.1/0.3/1/3) × gamma 2개(scale/0.01) × 보조 가중치 2개(0.25/1) = **32개 설정**이다. 실행 중 64개라고 안내한 수는 잘못 계산한 것이며 실제 실행은 32개다.

희토류 미첨가 대조군을 포함한 `training_RE_all_journals.csv` **326행 전체**를 최종 학습에 사용했다. 동일 시편이 들어 있는 서로 다른 버전의 CSV를 단순 결합하지 않았다. 앞서 추가 검증에서 성능이 떨어진 별도 비희토류 공정 66행은 이번 최종 학습에 포함하지 않았다. 비희토류 행도 양의 가중치로 사용하고, 한 논문의 많은 반복 행이 지배하지 않도록 논문당 가중치를 균형화했다.

| 평가 | log10(icorr) R² |
|---|---:|
| 기존 상 포함 고정 설정의 논문 제외 검증 | 0.1491 |
| 이번 상 포함 설정 중 최고 관찰값 | **0.1878** |
| 이번 설정 선택까지 포함한 중첩 논문 제외 검증 | **-0.1087** |
| 326행 학습 후 같은 희토류 첨가 41행을 다시 예측 | **0.9303** |
| 326행 학습 후 같은 전체 326행을 다시 예측 | **0.2175** |

최고 후보는 상/조직 포함, 결정립·분율 제외, SVR C0.3/gamma scale/epsilon0.1, 비희토류 보조 가중치0.25다. 미보고 상은 다른 시편의 다수 상으로 채우지 않고 `unreported` 범주로 처리했다. 모든 전처리는 검증 fold의 학습 자료에서만 계산했다. 각 평가 논문의 대조군까지 제외하여 같은 논문의 정보가 학습/검증에 동시에 들어가지 않게 했다.

**0.9303은 학습한 자료의 재예측 값이며 새 데이터 예측 성능이 아니다.** 중첩 검증이 음수이므로 일반화 성능 개선을 확정하지 않는다. 상 없이 조성·공정만 사용한 기존 최고 탐색값 0.2111보다 이번 상 포함 최고값 0.1878은 낮다. 따라서 상 포함 모델을 저장했지만 기존 기본 후보보다 우수하다고 승격하지 않는다. 지금까지 같은 데이터로 탐색을 반복한 점도 독립 새 문헌 검증이 필요한 이유다. 기존 부식전류/행은 수정하지 않았다.

파일:

- `model_all326.joblib`: 전체 326행으로 학습한 모델과 입력 정보.
- `comparison.csv`: 32개 설정 점수.
- `validation.json`: 선택 결과, 학습/검증 지표, 학습 입력 SHA256.
- `predictions.csv`: 전체 학습 재예측, 최고 고정 설정과 중첩 검증의 희토류 첨가 행 예측. 검증 대상이 아닌 행의 검증 예측은 결측이다.

재학습: `.venv/Scripts/python.exe -X utf8 -B tune_phase_model.py`

예측: `.venv/Scripts/python.exe -X utf8 -B predict_phase_model.py input.csv output.csv`

예측 입력은 기존 데이터의 동일 이름·단위 컬럼을 사용한다. 조성 범위는 앞서 합의한 중간값 규칙으로 처리하고, 없는 입력은 학습된 전처리로 대치한다. 실제 관찰하지 않은 상을 임의 입력하지 않는다.
