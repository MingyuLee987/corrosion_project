# 희토류 첨가 강재 문헌 추가 및 고정 시험 비교

2026-10-14. 기존 NaCl 자료 139행에 **5행**을 추가하여 **144행·196컬럼**으로 재학습했다. 신규 행은 희토류 첨가 **3행**, 해당 문헌의 비첨가 대조군 **2행**이다. 전체 희토류 첨가 행은 30행에서 **33행**으로 늘었다. 요청한 약 20행에는 도달하지 못했다. 확인되지 않은 전류밀도, 중복 시료, 전류밀도 없는 노출 시간을 추가 행으로 만들지 않았다.

## 수록 문헌

| 문헌 | 추가 시료 | 근거 |
|---|---|---|
| [27% Cr hyper duplex stainless steel (2022)](https://doi.org/10.1515/rams-2022-0284) | DSS1 비첨가, DSS3 RE 0.031 wt% | Table 1 조성, Sec 3.4 수치로 보고된 icorr, Sec 2 시험 조건. DSS2·DSS4는 수치 미확인으로 미수록 |
| [EH420 offshore steel (2023)](https://doi.org/10.1088/2053-1591/acc236) | 비첨가, Ce 0.0013·0.0019 wt% | Table 1 조성, Table 3 96시간 부식 시료의 PDP 전류밀도. 다른 노출 시간에는 전류밀도 수치가 확인되지 않아 미수록 |

두 논문의 공개된 원 논문 전문을 확인했다. 추출 사실·출처·위치는 [verified_extraction.json](verified_extraction.json)에 보관했다. 데이터의 source_sha256은 이 추출 기록의 해시이며, 원 논문 PDF 해시를 뜻하지 않는다. NaCl 몰농도는 wt% 또는 표기 불명확한 %에서 임의 변환하지 않았다. EH420의 S <0.002 wt%는 상한 컬럼에만 기록했고, 이전 오스테나이트 관찰을 위한 재가열 시간을 최종 공정 시간으로 넣지 않았다.

## 재학습 결과

목표는 `log10(icorr_A_cm2)`이다. 기존에 선택한 14입력 GBR 설정을 고정하고 새 자료를 학습에 추가했다. 기존 시험 **28행(희토류 6행)**의 record_id를 그대로 유지하여 **116행**으로 학습했다. 시험 점수에 맞춰 모델이나 입력을 재선택하지 않았다.

| 지표 | 추가 전 | 추가 후 |
|---|---:|---:|
| 전체 학습 R² | 0.9458 | 0.9475 |
| 전체 시험 R², 28행 | 0.8392 | 0.8406 |
| 희토류 학습 R² | 0.9797 | 0.9826 |
| 희토류 시험 R², 6행 | 0.8173 | **0.8052** |
| 희토류 시험 log10 MAE | 0.2351 | 0.2696 |
| 희토류 시험 2배 이내 | 5/6 | 4/6 |
| 희토류 시험 3배 이내 | 5/6 | 5/6 |
| 희토류 시험 5배 이내 | 5/6 | 6/6 |

전체 시험 R²와 5배 적중률은 개선되었지만, 희토류 시험 R²와 평균 오차·2배 적중률은 악화되었다. 따라서 희토류 예측 성능이 전반적으로 높아졌다고 결론내릴 수 없다. 이전에 사용한 시험 자료를 다시 비교한 탐색 결과이며, 독립적인 신규 시험 점수는 아니다. 같은 문헌의 다른 시료가 학습과 시험에 함께 있는 행 분할의 한계도 유지된다.

추가 학습 전에 기존 111행 모델로 새 문헌 5행을 예측한 R²는 **0.6256**이다. 이 중 희토류 3행에서는 **0.6389**였으나, 2배 이내 적중은 **0/3**, 5배 이내는 **1/3**, 10배 이내는 **2/3**이었다. 시료와 독립 논문 수가 매우 작고 목표값 범위가 넓어, R²만으로 예측 오차가 작다고 판단하면 안 된다.
