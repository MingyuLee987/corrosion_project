# 미량 원소 조성 추가 비교

기존 19입력 모델에 N·Al·Nb·V·Ti·Co·O·La·Ce 조성 컬럼을 추가하는 후보를 비교했다. 144행·196컬럼 데이터와 기존 시험 28행을 유지했다. GBR 설정도 고정했다. 학습 116행에서 논문별 4분할 검증의 희토류 R²를 기준으로 하나씩 추가하고, 최대 3개까지 추가하거나 점수가 더 좋아지지 않으면 중단하도록 정했다. 실제 선택된 추가 컬럼은 **Co_wt_pct 한 개**였으며, 실험 모델은 **20입력**이다.

| 지표 | 기존 19입력 | Co 추가 20입력 |
|---|---:|---:|
| 전체 학습 R² | 0.9477 | 0.9459 |
| 희토류 학습 R² | 0.9809 | 0.9792 |
| 전체 행 단위 검증 R² | 0.8217 | 0.7859 |
| 희토류 행 단위 검증 R² | 0.7782 | 0.7227 |
| 전체 논문 단위 검증 R² | −0.2428 | −0.2423 |
| 희토류 논문 단위 검증 R² | −0.4125 | **−0.3730** |
| 전체 기존 시험 R² | 0.8573 | 0.8481 |
| 희토류 기존 시험 R² | 0.9597 | 0.9066 |

모두 log10(icorr_A_cm2) 기준이다. 검증 R²는각 분할의 검증 예측을 모아 계산했다. 시험 점수는 입력 선택을 마친 뒤 계산했으며 선택 기준에 쓰지 않았다. Co 추가는 개발용 논문 단위 검증만 소폭 개선했고 행 단위 검증과 시험 성능은 낮아졌다. 따라서 조성을 더 넣을수록 성능이 일관되게 좋아진다고 볼 수 없다. 20입력 모델은 추가 실험으로 보관하며, 이전 모델과 기본 모델을 덮어쓰지 않았다.

Co가 보고된 시료는 **11/144행**뿐이다. 선택 결과는 Co의 독립적인 물리 효과를 입증하지 않는다. 결측 표시가 논문별 보고 차이를 반영할 수도 있다. La·Ce는 보고된 개별 조성만 입력 후보로 사용했고 혼합 희토류의 개별 함량은 추정하지 않았다. W·Ca는 보고값이 없어 후보에서 제외했다. 투입 목표량, 전류밀도, 부식 전위, 논문 ID는 새 입력으로 쓰지 않았다.

여러 후보를 같은 개발용 검증 자료에서 비교했으므로 선택된 검증 점수에는 선택 편향이 있다. 독립 중첩 검증 결과로 해석할 수 없다. 역사적 시험도 이미 관찰한 자료이고 희토류는 6행뿐이다.

재현: `.venv/Scripts/python.exe extend_composition_inputs.py`

[수치 결과](validation.json), [후보별 탐색 기록](search_history.json), [행별 예측](predictions.csv). `model_train_only.joblib`는 학습 116행 모델이고, `model_all144.joblib`는 전체 자료로 다시 학습한 실험 모델이며 위 시험 점수를 독립 성능으로 적용할 수 없다.
