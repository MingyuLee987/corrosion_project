# 희토류 첨가 부식 분석

`실행.bat`을 더블클릭하거나 PowerShell에서 `./run.ps1`을 실행합니다.
Python 환경이 없으면 Python 설치가 필요하며, 첫 라이브러리 설치에는 인터넷이 필요합니다.

- `corrosion_re_expand.py`: 독립 실행 코드. 47행/50행 비교와 일반강 PDP 자료를 추가한 98행/314행 분석을 실행합니다.
- `evaluate_ml.py`: 6개 모델과 2개 입력 집합을 98행/314행에서 논문 제외 검증합니다. `실행.bat`에서 분석 후 자동 실행하며, 평가만 다시 하려면 `.venv/Scripts/python.exe -B evaluate_ml.py`를 실행합니다.
- `data/training_51.csv`: 원본 입력(실제 47행).
- `data/training_RE_expanded.csv`: 실행 시 생성하는 50행 데이터.
- `data/training_PDP_augmented.csv`: 실행 시 생성하는 314행 데이터. 기존 98행에 공개 철근 PDP 216행을 추가했습니다.
- `data/non_RE_rebar_PDP216.csv`: 저자의 공개 부록에서 추출한 216행 입력. 실행에 필요합니다.
- `results/RE_expanded/`: 실행 시 생성하는 지표와 예측 결과.
- `requirements.txt`, `.venv/`: 실행 라이브러리와 환경.

결측값은 학습 폴드 안에서만 대체합니다. 현재 결과는 탐색 분석이며 별도 예측 배포 모델은 없습니다.
추가 3행의 출처·전사값과 기존 검증 PDF 해시를 코드에 보존하여 논문 PDF 없이 실행합니다.

모든 추가 행에 출처와 표/절 위치를 기록했습니다. `RE_wt_pct=0`은 희토류를 의도적으로 첨가하지 않았다는 모델상 표기이며, 잔류 희토류 함량을 측정하여 0으로 확인했다는 뜻은 아닙니다. `RE_content_status`와 비고에서 구분합니다.
P·S의 상한값은 별도 상한 컬럼에 보존하고 정확한 함량 컬럼에는 넣지 않습니다. 누락된 실험값은 추정하지 않습니다.
주조방식 추정은 별도 상태/비고에 남기며 예측 입력에는 사용하지 않습니다. 열처리 온도, 주조 온도, 사전 노출 온도와 PDP 온도를 구분합니다.

## 검증과 현재 결과

희토류 연구 논문 11편을 하나씩 통째로 제외하여 평가합니다. 제외된 논문은 학습과 내부 모델 선택에서 모두 빠집니다. 실제 희토류 첨가 33행의 논문별 평균 오차를 내부 선택 기준으로 사용합니다. 일반강 논문은 보조 학습 자료이며 이들 논문에 대한 검증 성능을 주장하지 않습니다.

`results/RE_expanded/non_RE_comparison.csv`에서 다음을 비교합니다.

- `historical_fixed8`: 기존 50행/8개 입력/기존 선택 기준.
- `target_only_fixed_core`: 50행/8개 입력/희토류 첨가 시편 중심 선택 기준.
- `previous_98_fixed_core`: 기존 98행/8개 입력/희토류 중심 선택 기준. 이번 216행을 제외하여 기존 결과를 재현합니다.
- `auxiliary_fixed_core`: 314행/8개 입력/동일한 희토류 중심 선택 기준. 중앙값 기준 모델은 보조 자료를 사용하지 않습니다.
- `target_only_nested`: 50행, 조성·시험 조건 입력 집합까지 내부 선택.
- `auxiliary_nested`: 보조 자료 비중 0/0.25/1과 입력 집합·모델을 내부 선택.

## 이번 216행 확장 결과

기존 98행에 실제 PDP 측정 216행을 추가하여 총 314행, 출처 논문 19편이 되었습니다. 추가 원자료는 72개 실험 조건과 조건당 3개 별도 반복 시편으로 구성합니다. 반복 시편을 복제하거나 합성하지 않았습니다. 같은 출처를 216개 독립 논문처럼 취급하지 않으며, 논문 크기의 역수로 학습 가중치를 적용합니다.

추가 자료에는 모르타르 내부 시편 144행과 공극수 용액 시편 72행이 있습니다. 정확한 강재 조성과 시험 온도·스캔 속도는 공개 부록에서 검증되지 않아 비워 두었습니다. 조성 결측을 강종 표준값이나 0으로 채우지 않습니다. 모델 내부의 학습 폴드에서만 대체하는 탐색 분석입니다. 원자료·출처 URL·부록 표/행 위치·원자료 SHA256·반복 시편 번호를 CSV에 기록했습니다.

모르타르 NaCl 함량은 혼합수에 첨가한 양이며, 자유 공극수 NaCl 농도로 옮기지 않습니다. `mixing_solution_NaCl_wt_pct`, `chloride_by_cement_wt_pct`, `relative_humidity_pct`, `water_cement_ratio`, `carbonation_state`, `test_specimen_type`으로 구분했습니다. 공극수 용액과 모르타르의 탄산화·비탄산화는 각각 다른 전해질 계열입니다. 데이터 출처는 원 연구 2023년 논문이며 2026년 재분석 논문을 독립 실험으로 중복 추가하지 않았습니다.

희토류 첨가 시편 33행/논문 11편을 제외 검증한 결과는 다음과 같습니다.

| 학습 비교 방식 | log10 MAE | 논문별 동일 비중 MAE | R² |
|---|---:|---:|---:|
| 기존 50행/기존 선택 기준 | 0.8573 | 0.9298 | -0.4380 |
| 기존 98행/희토류 중심 선택 기준 | 0.8181 | 0.9392 | -0.3697 |
| 추가 후 314행/동일 선택 기준 | 0.9547 | 1.1102 | -0.7828 |

이번 216행을 모두 학습한 고정 입력 방식은 기존 98행보다 희토류 첨가 시편의 평균 오차가 약 16.7% 증가했습니다. 보조 자료 비중과 입력 집합까지 내부 선택하는 방식도 314행에서 MAE 0.9698로 개선되지 않았습니다. 수집 목표는 충족했지만 추가 자료의 매질과 조성 결측이 희토류 예측에 도움이 된다는 근거는 없습니다. 314행 방식을 기본 예측 모델로 승격하지 않으며 기존 98행 비교를 유지합니다.

정확한 조성을 확인하고 희토류 실험과 유사한 강종·전해질 조건의 문헌을 늘리는 작업이 별도로 필요합니다. 비교 결과를 삭제하거나 가장 좋은 수치만 제시하지 않습니다. 문헌 추가와 검증을 반복하여 관측한 탐색 결과이므로 새로운 독립 논문으로 확인해야 합니다.

`non_RE_benchmark.json`에는 각 폴드의 선택·결측률·부트스트랩 비교·제외한 문헌과 사유를, `non_RE_heldout_predictions.csv`에는 시편별 실제값과 논문 제외 예측값을 저장합니다. 자세한 입력 집합은 코드와 JSON에서 확인할 수 있습니다. 논문 ID·부식전위·측정 부식생성물은 입력에 사용하지 않습니다.

## 머신러닝 모델별 평가

`results/ML_evaluation/model_comparison.csv`에 6개 모델(중앙값 기준, Ridge, SVR, Random Forest, Extra Trees, Histogram Gradient Boosting) × 2개 입력 집합 × 2개 데이터 규모의 결과를 저장했습니다. 전체 행, 희토류 연구 행 50개, 실제 희토류 첨가 행 33개를 각각 평가합니다. `heldout_predictions.csv`는 각 행의 논문 제외 예측값이며 `validation.json`은 입력·고정 모델 설정·각 폴드의 결측률을 담습니다.

314행에서는 19편, 98행에서는 18편을 하나씩 제외하며 같은 논문의 모든 반복 시편이 함께 빠집니다. 결측 대체·스케일링·범주 인코딩은 학습 폴드에서만 수행합니다. 평가값에 맞춘 하이퍼파라미터 조정은 하지 않았습니다. 모델 설정을 실행 전에 고정했으며 모델 순위는 관측한 비교 결과입니다. 순위를 보고 최적 모델을 선택하는 절차 자체를 독립 검증한 결과는 아닙니다.

314행 학습으로 희토류 첨가 33행을 평가한 대표 결과:

| 모델 | 입력 집합 | log10 R² | log10 MAE | 논문별 동일 비중 MAE |
|---|---|---:|---:|---:|
| 중앙값 기준 | 기본 8개 | -0.117 | 0.709 | 0.811 |
| SVR | 조성·시험 조건 | -0.125 | 0.768 | 0.869 |
| Ridge | 기본 8개 | -0.651 | 0.855 | 1.016 |
| Extra Trees | 기본 8개 | -0.631 | 0.889 | 1.027 |
| Histogram Gradient Boosting | 기본 8개 | -0.908 | 0.960 | 1.123 |
| Random Forest | 기본 8개 | -1.130 | 1.000 | 1.172 |

학습 모델 중 논문별 MAE가 가장 낮은 설정은 조성·시험 조건을 사용하는 SVR이지만 중앙값 기준보다 나빴습니다. SVR의 예측이 실제값의 2배 이내인 시편은 18.2%이며, 평균 로그 오차의 배수 환산은 약 5.86배입니다. 이 수치는 정확도(%)나 인과적 희토류 효과가 아닙니다. 평가된 모든 314행 머신러닝 설정의 희토류 시편 R²는 음수이며, 현재 모델의 새 논문 예측력은 부족합니다.

기존 문헌 추가 평가와 이번 중앙값 기준값은 다를 수 있습니다. 이번 기준 모델도 논문당 총 가중치를 같게 하여 학습합니다. 각 입력 집합·데이터 규모 내에서 동일하게 평가한 기준 모델과 비교해야 합니다. 학습 모델을 배포 모델로 승격하지 않았습니다.
